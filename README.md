# 🎓 Skill-Based Scholarship DAO

A decentralized autonomous organization (DAO) for managing skill-based scholarships on the Stacks blockchain.

## 🌟 Features

- 📝 Skill-based quizzes with token rewards
- 🗳️ Democratic scholarship proposal system
- 💰 Transparent fund management
- 🔐 Secure voting mechanism
- 🏆 Merit-based token distribution

## 📚 Smart Contract Overview

The contract implements:
- Governance token management
- Quiz creation and verification
- Scholarship proposal submission
- Voting system
- Automated fund distribution

## 🔧 Usage

### Quiz Participation
1. Complete available quizzes
2. Earn governance tokens based on performance
3. Use tokens for voting on scholarship proposals

### Scholarship Application
1. Submit proposal with required token stake
2. Provide project/study description
3. Wait for community voting
4. Receive funds if proposal passes

### Voting
1. Use earned tokens to vote on proposals
2. One token = one vote weight
3. Voting period: 144 blocks (~24 hours)

## 🚀 Getting Started

```bash
clarinet contract call --contract-name skill-based-scholarship-dao --function-name initialize --arg '"SCHOLAR"'
```
